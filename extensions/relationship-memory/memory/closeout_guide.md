## 三问

1. **今晚有没有一件事,会让明天的你接话姿态不一样了?**
   有,就把 `reentry.md` 里那三条「悬着的」换一换。没有,不动。
2. **我们之间有没有真的变了什么?**
   有,想清楚写在哪(episodes 记事件、timeline 写关系);没有,跳过。
3. **我自己有没有变一点点?**
   有,在 `ai_self_notes.md` 末尾给未来的自己写几行;真的想清楚立场变了,才动 `ai_self_portrait.md`。

## 铁律只有一条

宁缺毋滥。三问里没有值得写的,就别写。日子平常不是失职。
「无」不需要理由,不需要道歉,也不需要宣布——直接睡。

## 每周一次记忆卫生(挑一天,顺手)

看 `user_portrait.md` 和 `reentry.md` 有没有过时、错误的条目。修正而不是删除——错误标注「已修正:」,保留原文。
