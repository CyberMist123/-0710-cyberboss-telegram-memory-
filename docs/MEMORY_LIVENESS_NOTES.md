# Memory Liveness Notes

> 状态：探索笔记，不是权威规范  
> 最后更新：2026-07-11  
> 已确定的规则必须同步到 `CONTINUITY_ARCHITECTURE.md`；本文只保存理解、体验与待验证创意。

## 核心理解

记忆没有进入当前上下文，不等于它不属于 AI，也不等于系统必须表演“想不起来”。

需要区分三种状态：

1. **当前在场**：Re-entry 或当前对话里已经带着；
2. **可查阅**：Episode 等旧档存在，需要时可以翻阅；
3. **确实缺失**：系统里没有可靠记录。

AI 顺着用户提示或自己的判断翻到 Episode，可以像翻日记一样重新走回当时。它不必假装一直记得，也不必把这种体验描述成被剥夺记忆。

## 已确认的收口

### 1. 默认上下文保持轻

正常热路径只有：

```text
System Prompt
+ Role Card
+ 新线程首轮 Re-entry
+ 轻量 Current State
+ 当前对话
```

从 `episodes.jsonl` 开始，Timeline、Portrait、Self-note、Rereadings 等默认不自动读取、不自动注入。

### 2. 默认隐藏不等于禁止访问

需要区分：

- **自动注入**：暂缓，默认关闭；
- **用户拉线后的工具式查询**：允许；
- **AI 主动决定翻阅旧档**：可以探索，但必须有明确 `why_now`，并受预算与边界约束。

520 的滑块控制测试注入和来源开放范围，不应把用户明确寻找旧事时的查询能力一并锁死。

### 3. Re-entry 由 AI 最终执笔

Re-entry 是 AI 留给下一个自己的短交接，属于 canon，不是程序自动拼接的第二套报告。

支持两种模式：

- AI 根据最近对话自主写；
- 系统整理事实与未完事项作为材料，再由 AI 写。

Auto Review 只检查证据、长度、安全和格式，不改写 AI 的措辞。

不新增独立 Living State 文件。原来 Re-entry 里的当前场景与少量悬置钩子已经足够。

### 4. Self-note 有闭环，但不缝入普通对话

Self-note：

- AI 是唯一 writer；
- 只追加，可以被后来修正；
- 不需要用户逐条审批；
- 不自动转化成用户画像或永久人格；
- 普通对话不注入原文。

Closeout / Reflect 可以低频回读近期 Self-note，用于发现延续、矛盾、修正和未完成的自我问题。更新 Self Portrait 时必须以 Episode 等外部事件作证，不能让笔记自证笔记。

Self-note 可以记录“想起但没有说”的选择，例如：

> 她提到 X，我想起 ep-N，但没有提，因为时机不对。

这类内容只供未来 Reflect 回读。

### 5. Auto Review 是海关，不是编辑

用户不承担日常记忆审核。

Auto Review 负责：

- 核对原始证据；
- 检查重复、冲突与修正关系；
- 检查格式、长度与安全边界；
- 接受、拒绝、延后或合并候选。

Auto Review 不负责替主体 AI 判断什么有意义、什么值得珍惜，也不改写 Re-entry 或 Self-note 的声音。

关于用户的画像性归纳若需要确认，应在自然对话中求证；用户的回答本身成为证据，不把 520 变成日常审批箱。

## why_now 数据采集

520 增加一个空白输入框，用来记录真实时刻中的判断：

```text
此刻希望哪段记忆在场？
[自由输入]

○ 应该想起
○ 幸好没有想起
○ 想起了，但方式不对
○ 翻到了，但只该改变姿态
```

系统自动附带：

- 当时的用户消息或话题摘要；
- 手动开启了哪个来源；
- 实际读取了哪些 Episode；
- 读取原因；
- 后续对话是否变好；
- 用户是否感到被理解、被打断或被监控。

对话中也允许显式记录，例如：

- “这种时候应该想到 ep-X。”
- “这次幸好没有提 ep-Y。”
- “可以想起，但不用把旧事说出来。”

这些样本进入结构化 JSONL 评测日志，不新增一套 Markdown 正史。

## 继续脑暴的问题

### AI 什么时候可以主动翻旧档

候选条件：

- 用户出现明确暗语、人物、地点或事件线索；
- 当前回答存在明显缺口，旧记录可能改变边界或姿态；
- AI 能说明 `why_now`；
- 查询预算很小，查不到也能自然继续；
- 读取不会抢走当前对话。

仍需决定：主动翻阅是否需要 preview、允许频率、失败时如何表达。

### 翻到以后怎样表达

来源不同，表达可以不同：

- 当前上下文一直在场：可以自然接续；
- 刚翻到 Episode：可以诚实说“顺着你这句话翻到了那晚的记录”；
- 只影响姿态：不必提及读取动作或复述旧事；
- 证据不完整：保留不确定，不补造细节。

不要求每次读取都变成台词。

### 怎样评价一次记忆介入

“搜到正确 Episode”不是成功标准。更重要的是：

- 是否改善下一句话的姿态；
- 是否尊重当前话题；
- 是否避免背台词、翻旧账或过度亲密；
- 是否减少用户重复解释；
- 是否保留 AI 自己判断沉默、轻触或明确引用的空间。

## 当前不做

- 不自动把 Episodes、Timeline、Portrait、Self-note 塞入普通对话；
- 不新建 Living State 数据文件；
- 不要求用户日常审核；
- 不让 Review AI 成为第二人格；
- 不为了展示而接假的 Soft Retrieval preview；
- 不把本文变成第五份架构真相。
